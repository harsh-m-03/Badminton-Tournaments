# Badminton-Tournaments

Android Application using Java which helps to manage Badminton Tournaments. This application keeps track of every player’s
statistics. This application is being used by my society and was successful in managing more than 500 matches.
Using this an user can:
● Add Player Profile.
● Create and Manage Tournaments.
● Track Matches and points table in a Tournament.
● Track Weekly Activity.
● Records Player’s Statistics.

Database: Firebase
Language: Java
